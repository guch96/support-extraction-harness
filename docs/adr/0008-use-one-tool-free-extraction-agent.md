# 单个提取 Agent，由代码授权并读取来源

2026-10-18，用户在开源方案调研后确认改用单个无业务工具的提取 Agent。直接文本和按指定记录 ID 读取两种输入共用提取与修复流程；读取权限、数据获取、PII、安全上下文、严格校验、预算、审计及人工审核由代码控制。两种模式均最多三次模型调用，额外修复最多两次；指定记录最多读取一次，修复不重新读取。

此前 ADR-0001 保留特权与隔离两个模型角色用于权限演示，但本题的读取目标已确定，不需要模型自主选择工具。采用代码取数减少额外模型调用、消息配对及跨角色状态维护，保留实际授权边界；业务语义仍需独立评测，单模型并不意味着内容必然可信。双角色仅作为未来独立演示的可选方向，不属于本次必需交付，也不进入主链。

本决定替代 [ADR-0001](0001-isolate-extraction-from-tool-authority.md) 的双角色拓扑，并更新 ADR-0004 中角色 checkpoint 的数量；middleware 恢复所有权、会话恢复、原文保留与先保存补充等既有决定继续适用。模型输入与纠错话术以[上下文契约](../PROMPT_CONTEXT.md)为准。
