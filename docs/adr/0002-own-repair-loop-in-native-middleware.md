# 由原生 middleware 唯一控制输出修复

2026-10-18，用户确认提取模型返回 JSON 文本，由原生 middleware 校验，失败后记录原始输出和具体错误，再通过图跳转进行修复。每次运行最多额外修复两次，不叠加 ToolStrategy 自动纠错、wrapper 内重复调用或外层整次运行重跑；模型和来源读取异常直接进入统一失败出口，本次不启用网络自动重试。当前单提取角色拓扑见 [ADR-0008](0008-use-one-tool-free-extraction-agent.md)。

原生结构化输出也是可选方案，但其解析时机和自动恢复路径会改变 middleware 观察到的结果。使用唯一、显式的修复所有者，便于验证每次失败的证据、预算消耗及终止行为；格式恢复、业务语义评测和调用异常分别处理。
