# 将内容提取与工具权限分离

以下保留原决策历史。当前采用[ADR-0008：单个提取 Agent，由代码授权并读取来源](0008-use-one-tool-free-extraction-agent.md)，本次主链不再使用特权与隔离两个模型角色。

2026-10-18，用户确认保留双角色作为受限取数与权限隔离的演示。特权角色仅根据可信请求调用允许的读取工具，不生成业务操作；隔离角色负责处理不可信来源材料和生成提取结果。服务层直接取得六字段结果，特权上下文只接收宿主生成的状态和结果引用，不接收原始工具文本或提取结果中的自由文本。

也可以由确定性代码完成固定记录读取，但本项目保留模型角色以展示授权边界，而非宣称双模型能够提高提取准确率。选择只传状态和引用，是因为字段约束合格不能证明字符串安全；操作预览不属于本次交付。
