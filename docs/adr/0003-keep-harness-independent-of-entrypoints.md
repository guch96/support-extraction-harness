# Harness 独立于 HTTP 与页面入口

2026-10-18，用户要求 Harness 是独立模块，只提供原生 Harness 能力，便于后续扩展。输入安全、角色隔离、模型与工具策略、有限修复和执行状态由该模块控制；FastAPI 与 Gradio 属于外层适配器，不作为 Harness 的依赖，也不把 HTTP 请求、响应、状态码或页面状态传入核心。

将接口框架直接嵌入核心虽然便于初次集成，但会让后续复用和模型测试依赖 Web 环境。因此核心使用普通配置、领域输入与结果，持久化、模型及审计能力通过明确接口注入；应用层组装本题 schema、提取规则和模拟工具，再接入 HTTP 与页面。
