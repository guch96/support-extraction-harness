# 脱敏来源与受控原文使用不同保留规则

2026-10-18，用户确认 Q19：首次接收时分别保存受控原文和按顺序保留的脱敏来源材料。脱敏来源随会话生命周期保留，用于后续提取；原始来源和模型原始输出各自默认七天到期，活跃会话、补充或新审核项不延长旧原文保留。原文到期后审核入口明确显示“原文已过期”，脱敏丢失的信息不得靠历史模型答案或猜测补齐。

让原文跟随活跃会话保留可以减少信息损失，却会突破原文独立保留的边界；只保存模型答案又不能满足来源事实与模型输出分离。因此保留独立的脱敏来源，接受原文到期后审核证据不再完整、脱敏可能损失细节的限制。
