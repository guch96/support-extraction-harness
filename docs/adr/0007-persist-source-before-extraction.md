# 先保存来源补充，再执行提取

2026-10-18，用户确认 Q20：提交通过输入、会话、来源上限与同任务并发检查后，先可靠保存来源补充、脱敏材料及必要关联，再调用模型。来源保存失败时不调用模型，被拒绝的提交不进入来源历史；已保存补充不因后续 FALLBACK、中断或内部故障而撤销，下一次提取继续依据最新明确修正。

仅在模型成功时提交来源可以把保存与成功结果绑定，却会丢失用户已提供的修正并让下一轮回到旧事实。因此分开表示来源接收与提取结果，旧有效结果仅作为标明所属运行的历史记录展示；例如修正客户 ID 后模型失败，下一轮仍采用已保存的修正。
